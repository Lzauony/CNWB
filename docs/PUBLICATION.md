# 公开边界与后续发布

## 本版公开什么

公开32题既有冻结材料、SJ6完整协议及模板、通用计分/验证代码、合成技术测试和方法文档，以及已经公开的榜单汇总快照。题库不是秘密测试集，完整原题本来已在网站公开。

本包不复制真实作品，不导出私有逐篇等级与评语，不包含评审历史、原始API请求响应、内部开发映射、运行器状态、账户或密钥。作品仍可在既有网站阅读。协议中的说明、字段和判据属于此次授权整理的范围，不与历史真实评语混淆。

汇总快照只能说明当时公开展示的分数。没有逐篇记录，公众不能从该快照验证所有等级及论证。工具本身和合成测试可以验证；输入真实评审记录后的确定性算术可以复现。不得把这两种复现能力混为一谈。

## 防止公开参考集替代未见测试

开源不要求持续公开正在使用的全部测试材料。建议后续建立独立私有测试批次，冻结新情境、评测日期和版本；评测阶段不提供逐题答案或密集反馈，退役后再选择公开。只改题目标题、人名或措辞，不能可靠恢复未见性。未来榜单应分别标明公开参考集与新测试集，避免混合排名。

模型接触过公开材料不等于已证明污染；未知训练语料也不支持无污染声明。学习一般写作原则不是污染，针对同一测试情境记忆作品方案或评委偏好会削弱泛化解释。

## 发布前核验

1. 在仅包含本包的目录执行`cnwb.py check`及测试；确认不依赖父工作区。
2. 检查release-manifest.json文件清单，排除out/、.git/、缓存、真实评审与本地账户配置。
3. 区分代码、项目编写材料、第三方材料及模型输出的许可范围；保留SOURCES与版本说明。
4. 在新仓库或新发布路径上传本包文件，不将完整CNWB父目录直接推送。Git历史也不得包含先提交后删除的私有记录。
5. 同步网站时另行使用既有公开导出工具，不用本包或完整项目替换网站根目录。

基准代码仓库为[Lzauony/CNWB](https://github.com/Lzauony/CNWB)，网站仓库为[llmstory/llmstory.github.io](https://github.com/llmstory/llmstory.github.io)。两者分别维护；完整私有项目不是任一公开仓库的上传来源。本包整理和验证不执行模型API，发布代码也不自动重新生成或评审作品。
