# 验证与验收

```bash
python -B -X utf8 cnwb.py check
python -B -X utf8 -m unittest discover -s tests
```

日常开发执行上述命令；下载或发布完整包时另执行：

```bash
python -B -X utf8 cnwb.py check --release
```

| 检查 | 范围 |
|---|---|
| check | 冻结材料文件集合/哈希、32题及六维覆盖、合成算分、首页榜单一致性、JSON与Python语法、文档本地链接 |
| check --release | 上述全部，再核验发布文件集合、全部文件哈希、核心工具及公开成绩来源哈希 |

开发检查允许工具和普通文档与上一发布版不同，始终保护benchmark/题库、协议、计分定义及请求模板。发布检查要求当前内容完整匹配清单。两者不调用模型，不需要Git；只有维护者的`manifest`命令需要Git。

tools/manifests/release.json绑定公开包全部文件，tools/manifests/source.json绑定本版题库、协议、请求模板与核心工具文件。清单用于完整性检查，不是可信第三方签名或文学质量认证。工具与文档的审核改动用新软件版本发布；预览与更新清单的顺序见[贡献指南](../.github/CONTRIBUTING.md)。`manifest`拒绝改动本版冻结材料或公开成绩快照，不能用重算哈希替代材料版本审查。

测试使用明确标记的合成输入，覆盖：

- 32题库存、六维覆盖、生成请求与模板一致及全部B2维度组合。
- 作品/材料哈希、阶段、额外维度、重复题目与非法等级拒收。
- B2独立允许降至1级、升至5级或null，并覆盖B1；缺B2不进入完整计分。
- null单列、整题三维退出完整作品聚合、严格与显式可用作品口径。
- incomplete/non_delivery/交付冲突及规划无T4/无总分。
- 外层BOM/围栏、相同重复键、说明补空、额外字段附录；冲突键、混合文本、截断及NaN拒收。
- 机械诊断不改变等级、双方未舍入均分、不同作品拒绝平均、原精度并列排名。
- CLI实际运行、CRLF/BOM保存和拒绝覆盖既有输出。
- 作品文件与原始响应/接收证据组装、证据回放一致性、双输出预检、32题组装后实际计分。
- 开发/发布检查分离、清单预览无写入、Git范围约束、新软件版本要求及冻结材料/成绩保护。

测试保证材料绑定、结构接收和算术行为，不保证文学评委正确，不提供合成文本的文学解释。测试只使用本包材料，在独立目录运行。

CI在Python 3.10/3.13及Windows/Linux上执行开发检查和测试；main分支推送或手动运行时还执行发布检查。四组独立完成，不因一组失败取消其他组；结果摘要只列失败测试标识、异常类型及缺失模块名。PR无需为开发改动重算正式发布清单。CI没有API密钥、网络模型运行或发布权限。每次发布应检查实际CI运行结果；本地通过不等于GitHub CI已经执行。
