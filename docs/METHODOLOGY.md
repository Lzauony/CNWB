# 方法与解释边界

CNWB v1.0采用32道中文叙事创作任务与SJ6 v1.0六维评委协议。本文完整说明测量范围、两阶段判级、格式接收、聚合和排名，不需要其他版本的文档。题文、材料、指定三维与分级判据由本发布包固定。

## 测量范围

32题包括28题正文相关交付和4题长篇规划（S01/S02/S03/O01）。正文相关任务包含完整故事、对话主导故事、独幕短剧、长篇开头、修订和材料加工。长篇设定或提纲只测本次规划质量，不能证明长篇实写能力；固定初稿修订不能证明自稿修订；单篇有效新意不能证明跨作品多样性。

每题只评价指定三维，全库提供六维观察网络。T1—T6覆盖数19/16/15/19/12/15，详见[数据卡](DATASET_CARD.md)。网络不构成各类型统计等值或能力迁移证明。建议篇幅偏离客观记录并解释影响，不自动封顶或重新生成。

## 分级与阶段

完整判据以[GENERAL_PROTOCOL](../benchmark/protocols/sj6-v1/GENERAL_PROTOCOL.md)、[B1](../benchmark/protocols/sj6-v1/stage_B1.md)、[B2](../benchmark/protocols/sj6-v1/stage_B2.md)及每题动态schema为准。

1级核心功能未成立；2级部分成立但实现薄弱；3级成熟、可信、具体且有效；4级有显著超出成熟实现的具体成就；5级在优秀基础上继续证明精度、整合、深度或表现力的提升。题给要求的完成不能自动证明升档，也不能一概扣除。没有预定等级比例，不按模型声誉或目标排名调分。

B1独立判三维1—4或null，数字4且有交付的维度进入B2。B2不见B1分数和理由，重新独立判**1—5或null**，最终覆盖入围维度。未入围维度保留B1；必需B2缺失时对应分数留空。正式评审仅有B1和B2两个阶段。

每个数字等级需文本证据及作用说明，四五级还需升档证明与最强限制审查。程序核验材料哈希、阶段、指定维度、类型和枚举，可定位连续引文并生成机械诊断；不能认证文学语义。空论证、错引或语义冲突保留为诊断，不自动改分、删分或重抽。明确null保留，不改写成数字。

格式接收仅允许公布的外层JSON围栏/BOM空白、相同值且相同递归类型的重复键、说明字段补空和非维度集合的额外字段移入附录。冲突重复键、额外维度、缺等级、错哈希和非法枚举拒收。原始文本和容错证据保留。不能从混合文本截取一个貌似可用的JSON。

## 单评委聚合

每题每维保留第一份符合材料、结构和阶段接收契约的响应。只有delivery_state=delivered且本题全部指定三维最终等级为整数，才是完整评分作品。null、缺失B2、non_delivery、delivery_conflict及incomplete单列，不补零。某题仅一维null时，该题全部三维退出完整作品聚合，按本基准的完整作品口径计算。

对每维d，在本范围完整作品中所有指定d的题目等权平均：

`dimension_score[d] = 20 × sum(final_grade[t,d]) / observed_complete_tasks[d]`

`total = Σ weight[d] × dimension_score[d]`

权重为20/20/15/20/15/10%。等级等距换算是描述性假设，理论范围20—100，不是准确率或百分位。全32与正文28独立计算；规划4没有T4，不计算六维总分，不能把其余权重归一化生成新总分。

默认strict：全部计划题目完整且六维均有观测才生成总分。维度输出同时报告实际n/planned和可用均值，部分覆盖的均值不能冒充完整成绩。显式available-complete-works：使用实际完整评分题目，各维有观测时可给加权总分，必须保留排除题目、原因与选择理由；完整性标记仍为false。该选项适用于预先声明的缺项分析，测评前须声明所选口径。

## 双评与排名

固定同文的两个评委各先独立聚合，再将对应总分及维度百分分各按50%取平均，使用未四舍五入原值。任一方对应分数null，均分也null；不另取共同题目重算，所以双方覆盖率可能不同，必须报告。原两份评审保持独立。

按原精度降序，精确同分使用竞争排名（1、1、3），null无名次；显示四舍五入不得决定先后。不同题库/协议版本、轮次、评委及生成条件须分列。平均工具核对同一作品记录的内容哈希，不能把同名模型不同轮次平均。

## 局限

- 使用模型评委，未经过独立人工金标校准。多评委一致不等于正确；分歧也不能仅凭模型身份判定孰是孰非。
- B1未判4的维度没有B2，存在首轮漏判风险。双阶段不等于全面消除偏差。
- 32题规模有限，题目、轮次和评委都可能造成波动。小分差不能宣称统计显著；本版没有为单轮榜单生成置信区间。
- 生成接口、思考档位和预算可能不同。模型能力或有波动，榜单描述本次实测，不能视作完全受控预算比较。
- 评委推断的阅读效果并非实际人类偏好、投入或受触动的测量。
- 本集已公开，后续模型可能见过题文或作品。保持公开参考轨道，并另行建立新的未公开测试批次；仅改名/改写不能恢复未见性。

## 复现的两层含义

给定同一作品和同一B1/B2记录，离线哈希核验、投影和算术应可复现。重新调用生成模型或评委模型存在随机性及供应商版本变化，不能保证得到原文本或原等级。本包公开汇总快照，但未公开榜单的逐篇评审，故不宣称已发布榜单能由公众从零逐篇复核。
