# 公开榜单汇总

`published-leaderboard.json`为2026-10-08从公开网站导出的汇总快照，保留数值精度。来源及SHA-256见source-manifest.json。它包含模型展示配置和评委汇总结果，不包含逐篇评语或逐题等级。

该文件采用网站数据结构，供查看和研究展示口径，不是`cnwb.py score`输入。复算需要自己的generation/evaluation文件；仅有汇总快照不足以逐篇核验榜单。

模型组数可能多于模型数，因为不同配置单列。部分组采用31题可用完整作品口径，不能当作32题完整成绩。网站双评均分使用双方独立汇总值，缺项状态保留。

合成测试成绩只位于examples/，不得放入实测榜单。离线工具不调用模型。
