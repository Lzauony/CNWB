`published-leaderboard.json`为2026-10-08从既有网站仓库导出的公开汇总快照，保留原始字节与精度；来源和SHA-256在source-manifest.json。它包含展示配置及各评委的汇总结果，不包含真实逐篇评语或逐题等级。

该文件沿用网站数据结构，供研究展示口径，不是`cnwb.py score`的输入。使用计分器需自己的generation/evaluation文件。公开快照不足以从零复算所有历史评分；本版不声称实现这一层历史复核。

展示选择与完整历史存档不同，模型组数可能多于模型数。某些组采用已授权的31题可用完整作品口径，不能当作32题完整成绩。当前网站的50/50双评平均使用双方独立汇总值；原始分数与缺项状态保留。
